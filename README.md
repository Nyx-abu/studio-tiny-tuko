# Studio Tiny Tuko — SiniGang Show Bible & Production Hub

Official web prototype and production showcase for **Studio Tiny Tuko**, an independent animation studio in active pre-production for their debut animated series, ***SiniGang***.

Created and directed by **Camille Anne Ongjoco**.

---

## ✦ Core Design & Production Ethos

- **100% Human Craft &bull; Zero Generative AI:** Every character turnaround, expression, background, and concept key is hand-drawn by human artists.
- **Editorial Art Book Design:** Warm `#FCFCFC` canvas, typography in Rubik, and zero card boxes or generic pill buttons.
- **Authentic 1:1 Inabel Weaving Ribbon:** Custom repeating geometric ribbon trim matched from studio branding and heritage patterns.
- **Bento Grid Vis-Dev Archive:** Asymmetric, gallery-grade presentation of environment concepts by `cloudyning` and creature studies by `mikkusushi`.
- **Bencho UI Audio:** Lightweight, browser-synthesized Web Audio API tactile click interactions.
